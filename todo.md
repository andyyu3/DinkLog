This checkpoint involves demonstrating your ability to do the following:

Install your app on a REAL, PHYSICAL device (Android or iOS);

Debug your app (e.g., step through code and set breakpoints);

Profile your app using one or more profilers (e.g., Android Studio’s CPU or memory profilers, or Instruments for iOS);

Implement one Activity and a couple Fragments for your app’s UI, plus log their lifecycle methods. The Fragments and Activity MUST BE key parts of your app’s screen flow, not just “dummy data.” Log the Activity lifecycle methods onCreate(), onStart(), onResume(), onPause(), onStop(), and onDestroy() in the Activity; for each Fragment, log these methods as well as onCreateView() and onDestroyView().

Other platforms/frameworks: You MUST implement one or two “screens” for your app or game if you build for iOS or use another framework (e.g., Unity or React Native). If you use a declarative UI framework (like Jetpack Compose or SwiftUI), include log messages in your composables to see the app’s lifecycle. (In this case, you fulfill this requirement by creating one Activity and two composable screens with navigation between them.)
